Kode 1 — Kondisi Awal

🟨 (Event - Kuning): Ketika bendera hijau diklik
🟪 (Looks - Ungu): Ganti costume ke [Celengan Kosong]
🟧 (Control - Oranye): Tunggu 7 detik
🟪 (Looks - Ungu): Katakan pesan aman menabung selama 4 detik
🟪 (Looks - Ungu): Katakan "Yuk Nabung di Bank" selama 2 detik

🟨 (Event - Kuning): Ketika sprite ini diklik
🟪 (Looks - Ungu): Costume berikutnya
🟪 (Looks - Ungu): Katakan "Terima kasih sudah menabung!" selama 2 detik

Kode 3 — Tambahkan Suara

🟨 (Event - Kuning): Ketika sprite ini diklik
🟪 (Looks - Ungu): Costume berikutnya
🟣 (Sound - Pink): Mulai suara [coin/cash register]

Kode 4 — Backdrop Opsional

🟨 (Event - Kuning): Ketika bendera hijau diklik
🟪 (Looks - Ungu): Ganti backdrop ke [Kamar]
🟪 (Looks - Ungu): Ganti costume ke [Celengan Kosong]

Project yang Akan Kamu Buat

Di sesi ini, kamu akan membuat project Evolusi Tabungan. Sprite celengan tidak langsung penuh, tetapi berubah bertahap setiap kali diklik.

Project ini menggabungkan coding dan Financial Literacy. Dari sisi coding, kamu belajar memakai costume dan next costume. Dari sisi kebiasaan baik, kamu belajar bahwa tabungan biasanya bertambah sedikit demi sedikit.

Inti sesi

Satu klik menjadi satu langkah kecil. Jika dilakukan berulang, celengan terlihat makin penuh.

Alur Belajar

Kita akan mulai dari konsep visual dulu, lalu masuk ke project. Kamu tidak perlu langsung membuat project yang ramai. Yang penting, celengan berubah dengan urutan yang benar.

Urutan belajar

  1. Mengenal costume, backdrop, dan transisi visual.
  2. Mengurutkan kondisi celengan.
  3. Mencoba simulasi perubahan celengan.
  4. Menyusun pseudocode Scratch.
  5. Mengecek hasil dengan checklist dan debugging.

Persiapan Sebelum Coding

Project ini membutuhkan sprite yang punya beberapa costume. Kalau sprite hanya punya satu costume, blok next costume tetap bisa dipasang, tetapi perubahannya tidak akan terlihat.

Yang perlu dicek

Buka tab Costumes dan pastikan urutannya masuk akal: celengan kosong, celengan setengah penuh, lalu celengan penuh.

Costume dengan Bahasa Sederhana

Bayangkan satu orang yang bisa berganti baju. Orangnya tetap sama, tetapi tampilannya berubah. Nah, di Scratch, tampilan berbeda itu disebut costume.

Untuk project ini, sprite celengan punya beberapa costume. Costume pertama menunjukkan celengan kosong, costume kedua menunjukkan mulai terisi, dan costume ketiga menunjukkan celengan penuh.

Membaca Perubahan Costume

Costume membuat perubahan terlihat oleh pemain. Tanpa costume, pemain mungkin tidak sadar bahwa celengan sudah bertambah penuh.

Kenapa harus berurutan?

Kalau urutan costume dibalik, celengan bisa terlihat penuh dulu, lalu kosong. Ceritanya jadi membingungkan.

Backdrop dan Cerita

Backdrop membantu penonton memahami tempat cerita. Misalnya, celengan di kamar menunjukkan kebiasaan menabung di rumah. Backdrop bank bisa memberi pesan bahwa uang bisa disimpan dengan aman bersama orang tua.

Perhatikan bedanya: costume mengubah tampilan sprite, sedangkan backdrop mengubah latar panggung.

Kenapa Perlu Transisi?

Kalau celengan langsung berubah dari kosong menjadi penuh, ceritanya terlalu cepat. Dengan transisi, pemain bisa melihat prosesnya: mulai kosong, lalu terisi, lalu penuh.

Hubungannya dengan menabung

Tabungan biasanya tidak langsung besar. Kita mengisinya sedikit demi sedikit sampai akhirnya terkumpul.

Latihan Sebelum Scratch

Simulasi ini meniru cara kerja next costume. Setiap kali celengan diklik, tampilannya berpindah ke costume berikutnya.

Di Scratch nanti, perubahan seperti ini dibuat dengan event when this sprite clicked, lalu diikuti blok next costume.

Mengurutkan Cerita Visual

Urutan costume harus mendukung cerita. Dalam project ini, cerita yang ingin ditampilkan adalah tabungan bertambah. Karena itu, urutan yang paling masuk akal adalah kosong, setengah penuh, lalu penuh.

Kalau urutan salah, project masih bisa berjalan, tetapi pesan ceritanya bisa membingungkan.

Cara Kerja Next Costume

Blok next costume seperti tombol “lanjut ke tampilan berikutnya”. Scratch mengikuti urutan costume yang ada di tab Costumes.

Tips

Kalau perubahan tidak sesuai, jangan langsung ubah blok. Cek dulu urutan costume di tab Costumes.

Memecah Project Menjadi Dua Script

Project lebih mudah dibuat jika dibagi menjadi bagian kecil. Pada sesi ini, ada script untuk mengatur kondisi awal dan script untuk merespons klik pada celengan.

Dengan cara ini, kamu bisa mengetes satu bagian dulu sebelum menambahkan bagian lain.

Kondisi Awal Project

Script ini membuat project selalu dimulai dengan rapi. Saat Green Flag diklik, celengan kembali ke costume kosong. Ini penting agar setiap kali project dijalankan ulang, ceritanya dimulai dari awal.

Kenapa ada pesan?

Pesan singkat membantu pemain memahami bahwa menabung bisa dilakukan dengan aman, misalnya bersama orang tua atau melalui bank.

Interaksi Utama

Script ini adalah bagian utama project. Saat pemain mengklik celengan, Scratch menjalankan blok yang tersambung di bawah event when this sprite clicked.

Blok next costume membuat celengan terlihat bertambah penuh. Blok say memberi respon agar project terasa lebih hidup.

Suara Sebagai Bonus

Suara tidak wajib, tetapi bisa membuat project terasa lebih seru. Jika kamu menambahkan suara koin, pemain akan mendapatkan tanda bahwa kliknya berhasil.

Gunakan volume aman

Pastikan suara tidak terlalu keras agar tidak mengganggu teman satu kelas.

Backdrop Tambahan

Backdrop adalah fitur tambahan. Project tetap berhasil tanpa backdrop, tetapi backdrop bisa membuat cerita lebih jelas.

Kamu bisa memakai backdrop kamar untuk awal cerita, lalu backdrop bank untuk pesan akhir. Namun, pastikan costume celengan tetap menjadi fokus utama.

Cek Pemahaman

Pertanyaan ini memastikan kamu paham peran setiap blok. next costume mengubah tampilan sprite, sedangkan switch backdrop mengubah latar panggung.

Debugging Tanpa Panik

Debugging adalah mencari bagian yang belum sesuai. Jangan langsung menghapus semua blok. Cek satu masalah dulu, lalu jalankan ulang project.

Urutan cek paling mudah

  1. Cek event.
  2. Cek blok yang tersambung.
  3. Cek urutan costume.
  4. Cek suara atau backdrop jika memakai bonus.

Daftar Blok

Tabel ini bisa kamu jadikan pengingat saat menyusun project. Fokus utama project ada pada when this sprite clicked dan next costume.

Blok suara dan backdrop boleh ditambahkan setelah project utama berhasil.

Checklist Berhasil

Output minimum adalah target wajib. Project tidak harus penuh efek dulu. Yang penting celengan bisa berubah secara berurutan dan pesan muncul dengan jelas.

Misi berhasil jika

Sprite memiliki minimal 3 costume, costume berubah saat diklik, dan project bisa dijalankan ulang dari awal.

Challenge Setelah Project Utama

Challenge hanya dikerjakan setelah output minimum selesai. Jangan menambah terlalu banyak efek saat project utama masih belum jalan.

Kalau ingin menambahkan costume keempat, pastikan urutannya tetap jelas dan ceritanya masih nyambung.

Refleksi Akhir

Hari ini kamu belajar bahwa animasi bisa bercerita. Dengan costume yang tersusun rapi, celengan terlihat seperti sedang berubah dari kosong menjadi penuh.
