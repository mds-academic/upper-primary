Sesi 14: Toko Interaktif

Kiko membuka toko buku. Hari ini kita akan membuat program yang dapat mengecek kondisi barang dan memberikan respons seperti kasir sungguhan.

Misi Hari Ini

Membuat simulasi toko buku menggunakan broadcast dan if-then-else.

Target Belajar

  • Mengirim pesan dengan broadcast.
  • Menerima pesan dengan when I receive.
  • Mengecek status barang dengan costume name.
  • Menggunakan if-then-else untuk membuat keputusan.

Cerita Toko Kiko

🛒

Pembeli

Memilih barang.

✏️

Pensil

Memiliki status tersedia atau terjual.

🧑‍💼

Kasir

Memberikan jawaban.

Bagaimana Program Berjalan?

  1. Pembeli klik barang.
  2. Program mengecek kondisi barang.
  3. Barang mengirim broadcast.
  4. Kasir menerima pesan.
  5. Kasir memberikan respons.

Mengenal Broadcast

Broadcast seperti mengirim pengumuman kepada sprite lain.

Contoh pesan:

📢 barang tersedia

📢 barang habis

Mengenal If-Then-Else

If-Then-Else membantu program mengambil keputusan.

Jika barang tersedia → katakan barang tersedia.

Jika tidak → katakan barang habis.

Costume Sebagai Status Barang

Costume tidak hanya untuk mengubah tampilan. Pada project ini, costume digunakan sebagai tanda kondisi barang.

  • tersedia = barang masih ada
  • terjual = barang sudah dibeli

Membaca Costume Name

Blok costume name membaca nama costume yang sedang digunakan.

Operator = membantu mengecek apakah nama costume sama dengan yang dicari.

Kode Awal Pensil

Saat Green Flag ditekan, pensil kembali ke kondisi tersedia.

Mengecek Kondisi Barang

Jika costume name = tersedia, program mengirim pesan barang tersedia.

Pesan dari Pensil

Setelah dicek, Pensil mengirim pesan sesuai kondisi.

Respons Kasir Kiko

Kasir Kiko menunggu pesan dari Pensil.

Simulasi Transaksi

  1. Klik pensil saat tersedia.
  2. Kasir menerima pesan barang tersedia.
  3. Pensil berubah menjadi terjual.
  4. Klik lagi untuk melihat kondisi barang habis.

Pesan dari Pensil

Pada project Toko Interaktif, Pensil berperan sebagai barang yang akan dibeli. Saat Pensil diklik, program harus mengecek terlebih dahulu kondisi barang. Apakah Pensil masih tersedia atau sudah terjual?

Program menggunakan costume name untuk membaca kondisi barang. Costume bukan hanya untuk mengubah tampilan, tetapi juga dapat digunakan sebagai tanda status sebuah objek.

Jika costume name = tersedia

  • Pensil mengirim broadcast barang tersedia.
  • Kasir Kiko menerima pesan tersebut.
  • Kasir memberi tahu pembeli bahwa barang masih bisa dibeli.

Jika kondisi tidak terpenuhi

  • Pensil mengirim broadcast barang habis.
  • Kasir memberi tahu bahwa Pensil sudah tidak tersedia.

Urutan berpikir programnya adalah: Klik barang → Cek kondisi → Kirim pesan → Kasir memberikan respons.
